# 🍍 .github de Pineapple

Este repositorio contiene la configuración de la organización **Pineapple** ([@PineappleVA](https://github.com/PineappleVA)) en GitHub.

## 📁 Estructura

| Ruta | Contenido |
|:---|:---|
| [`profile/`](profile/) | El [`README.md`](profile/README.md) que se muestra en el perfil público de la organización |
| [`assets/`](assets/) | Logotipos e imágenes usados en el perfil |

## 🖥️ Perfil de la organización

El archivo `profile/README.md` se muestra automáticamente en la página principal de la organización: **[github.com/PineappleVA](https://github.com/PineappleVA)**. Al editarlo, cambia el perfil visible de toda la organización.
